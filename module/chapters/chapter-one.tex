\section*{GenAI Terarah di Bab Ini}

AI generatif\index{AI generatif} atau GenAI adalah layanan seperti ChatGPT, Gemini, dan Claude yang dapat menjelaskan kode, menebak keluaran program, dan menuliskan program dari perintah dalam bahasa sehari-hari. Perintah itu disebut \textit{prompt}\index{prompt}. Buku ini memakai GenAI secara terarah. \textit{Prompt} memberi GenAI peran sebagai pendamping belajar dan membatasinya agar menjelaskan, bertanya balik, dan memeriksa jawaban tanpa menuliskan penyelesaian. Program tetap diketik dan dijalankan sendiri, dan setiap penjelasan GenAI dicocokkan dengan hasil menjalankan kode karena GenAI bisa keliru.

Di bab ini, GenAI dapat membantu ketika pemasangan Python atau program pertama gagal, misalnya saat Command Prompt tidak mengenali perintah \texttt{python}. Tempelkan pesan kesalahannya, sebutkan sistem operasi yang dipakai, lalu minta GenAI menjelaskan penyebabnya dan langkah pemeriksaannya satu per satu. Listing yang belum dipahami dapat dijelaskan dengan \textit{prompt} pada Listing~\ref{lst:b16-prompt-penjelasan}, dan soal latihan baru dapat diminta dengan \textit{prompt} pada Listing~\ref{lst:b16-prompt-latihan}. \section{Sejarah Pemrograman dan Python}

Pemrograman komputer dimulai pada abad ke-19 dengan penemuan mesin analitik oleh Charles Babbage dan program pertama yang ditulis oleh Ada Lovelace. Sejak itu, pemrograman telah berkembang pesat dengan munculnya bahasa-bahasa pemrograman awal seperti Fortran, COBOL, dan Lisp pada tahun 1950-an. Pada tahun 1970-an dan 1980-an, bahasa pemrograman seperti C, Pascal, dan Basic memperkenalkan konsep-konsep baru dalam pemrograman. Kini, berbagai bahasa pemrograman modern seperti Python, JavaScript, dan Rust digunakan dalam berbagai aplikasi.

Python merupakan bahasa pemrograman \textit{high-level} serbaguna yang pertama kali diperkenalkan pada tahun 1991 oleh Guido van Rossum (GvR). Bahasa ini dirancang agar mudah dipahami dan memiliki struktur kode yang jelas (\textit{readable}), serta mendukung fitur penanganan kesalahan (\textit{exception\index{exception} handling}). Dengan tujuan tersebut, Python berhasil berkembang menjadi bahasa pemrograman yang dapat dimanfaatkan di berbagai bidang. Python merupakan bahasa pemrograman multi-paradigma, yang artinya dapat menggunakan gaya/metode\index{metode} beragam dalam penulisan kode. Saat ini, Python banyak digunakan untuk pengembangan aplikasi web (\textit{server-side}), analisis data, hingga penerapan kecerdasan buatan dan pembelajaran mesin (\textit{machine learning}).

Python dibuat di CWI, Belanda, sebagai penerus bahasa bernama ABC \cite{py-history}. Guido van Rossum mulai mengerjakannya pada liburan Natal 1989, berbekal pengalaman membuat bahasa ABC. Dari bahasa itu Python mewarisi antara lain pemakaian indentasi\index{indentasi} untuk mengelompokkan perintah \cite{py-faq-general}. Namanya tidak berasal dari ular, melainkan dari acara komedi BBC \textit{Monty Python's Flying Circus} \cite{py-faq-general}.

\section{Python Sebagai Bahasa Interpreter}
Python merupakan bahasa pemrograman yang termasuk ke dalam kategori
\textit{interpreted language}. Artinya, kode program Python tidak
dikompilasi terlebih dahulu menjadi file biner yang dapat dieksekusi,
melainkan dijalankan baris demi baris oleh sebuah program bernama
\textbf{interpreter\index{interpreter}}.

Interpreter bertugas membaca kode Python, menerjemahkannya, lalu
menjalankannya secara langsung. Hal ini membuat proses pengembangan
program menggunakan Python menjadi lebih fleksibel, karena kita bisa
langsung menuliskan kode dan melihat hasil eksekusinya tanpa melalui
tahap kompilasi.

Perbedaan keduanya mirip dua cara menerjemahkan. \textit{Compiler\index{compiler}} seperti penerjemah buku: seluruh naskah diterjemahkan dulu, lalu hasilnya dapat dibaca kapan saja tanpa penerjemah. \textit{Interpreter} seperti juru bahasa di seminar: kalimat diterjemahkan saat itu juga, dan juru bahasa harus hadir setiap kali acara berlangsung.

Pembagian ini tidak sepenuhnya tegas pada Python, karena Python menerjemahkan kode lebih dahulu menjadi \textit{bytecode\index{bytecode}} sebelum menjalankannya \cite{py-glossary-interpreted}. Langkah itu terjadi otomatis, sehingga berkas sumber tetap dapat dijalankan langsung tanpa membuat berkas program terlebih dahulu.

\noindent
Pada Gambar \ref{fig:compiler-vs-interpreter} dapat dilihat perbedaan
utama antara \textit{compiler} dan \textit{interpreter}.  
\begin{itemize}
	\item \textbf{Compiler}: Menerjemahkan seluruh kode sumber menjadi file biner terlebih dahulu, kemudian hasilnya dapat dijalankan berulang kali tanpa perlu proses kompilasi ulang.
	\item \textbf{Interpreter}: Menjalankan kode baris demi baris secara langsung, sehingga lebih mudah untuk debugging\index{debugging} dan eksplorasi.
\end{itemize}

\noindent
\textbf{Kelebihan Python sebagai bahasa interpreter:}
\begin{enumerate}
	\item Mudah digunakan untuk pemula karena tidak perlu memahami proses kompilasi.
	\item Memungkinkan interaksi langsung melalui \textit{interactive shell}.
	\item Sangat fleksibel untuk \textit{prototyping} dan eksperimen cepat.
\end{enumerate}

\noindent
\textbf{Kekurangan Python sebagai bahasa interpreter:}
\begin{enumerate}
	\item Lebih lambat dibandingkan bahasa yang dikompilasi murni (seperti C, C++, atau Java).
	\item Program Python membutuhkan interpreter terpasang di sistem agar bisa dijalankan.
\end{enumerate}

\section{Instalasi di Windows}
Untuk menginstal Python di Windows, ikuti langkah-langkah berikut:

\begin{enumerate}
\item Unduh installer Python terbaru dari situs resmi \href{https://www.python.org/downloads/}{python.org}.
\item Jalankan file installer \texttt{.exe} dan ikuti petunjuk untuk menyelesaikan instalasi.
\item Saat instalasi, centang opsi \textbf{``Add Python to PATH''} agar Python otomatis dikenali di Command Prompt.
\item Ikuti petunjuk instalasi hingga selesai.
\item Verifikasi instalasi dengan membuka Command Prompt lalu ketik (Listing~\ref{lst:b1-memeriksa-instalasi-windows}):
\begin{lstlisting}[language=bash, caption={Memeriksa instalasi Python di Windows}, label={lst:b1-memeriksa-instalasi-windows}]
python --version
pip --version
\end{lstlisting}
\end{enumerate}

PATH adalah daftar folder yang diperiksa sistem operasi saat sebuah perintah diketik. Bila folder Python tidak ada dalam daftar itu, Command Prompt menjawab bahwa perintah \texttt{python} tidak dikenali, walaupun Python sudah terpasang. Bila hal ini terjadi, jalankan ulang installer dan centang opsi tersebut.

Perintah verifikasi menampilkan nomor versi, misalnya \texttt{Python 3.12.3}. Program \texttt{pip} adalah pengelola paket\index{paket}, yaitu alat untuk memasang pustaka tambahan yang dibuat orang lain.

\section{Instalasi di macOS}

Untuk menginstal Python di macOS, ikuti langkah-langkah berikut:

\begin{enumerate}
\item Unduh installer Python terbaru dari \href{https://www.python.org/downloads/macos/}{python.org}.
\item Jalankan file installer \texttt{.pkg} dan ikuti petunjuk hingga selesai.
\item Alternatif lain, Anda bisa menggunakan Homebrew dengan menjalankan perintah berikut di Terminal (Listing~\ref{lst:b1-memasang-dengan-homebrew}):
\begin{lstlisting}[language=bash, caption={Memasang Python dengan Homebrew}, label={lst:b1-memasang-dengan-homebrew}]
brew install python
\end{lstlisting}
\item Setelah instalasi selesai, verifikasi dengan perintah (Listing~\ref{lst:b1-memeriksa-instalasi-macos}):
\begin{lstlisting}[language=bash, caption={Memeriksa instalasi Python di macOS}, label={lst:b1-memeriksa-instalasi-macos}]
python3 --version
pip3 --version
\end{lstlisting}
\end{enumerate}

Homebrew adalah pengelola paket\index{paket} untuk macOS, sehingga perintah \texttt{brew} hanya berjalan bila Homebrew sudah terpasang. Pada macOS dan Linux, perintahnya biasanya \texttt{python3} dan \texttt{pip3}, agar tidak tertukar dengan versi lama Python.

\section{Instalasi di Linux}

Untuk menginstal Python di Linux, ikuti langkah-langkah berikut:

\begin{enumerate}
\item Buka terminal dan jalankan perintah berikut untuk memastikan repositori diperbarui dan Python terpasang (Listing~\ref{lst:b1-memasang-linux}):
\begin{lstlisting}[language=bash, caption={Memasang Python di Linux}, label={lst:b1-memasang-linux}]
sudo apt update
sudo apt install python3 python3-pip
\end{lstlisting}
\item Verifikasi instalasi dengan perintah (Listing~\ref{lst:b1-memeriksa-instalasi-linux}):
\begin{lstlisting}[language=bash, caption={Memeriksa instalasi Python di Linux}, label={lst:b1-memeriksa-instalasi-linux}]
python3 --version
pip3 --version
\end{lstlisting}
\end{enumerate}

Perintah \texttt{sudo} menjalankan perintah sebagai administrator, sehingga sistem akan meminta kata sandi. Perintah \texttt{apt update} memperbarui daftar paket\index{paket}, dan \texttt{apt install} memasang paket yang disebutkan. Perintah \texttt{apt} berlaku untuk Debian, Ubuntu, dan turunannya, sedangkan distribusi lain memakai pengelola paket yang berbeda.

\section{IDE dan Editor untuk Python}

\subsection{Apa Itu IDE?}

Integrated Development Environment (IDE\index{IDE}) adalah perangkat lunak yang menyediakan fasilitas lengkap untuk pengembangan perangkat lunak. IDE umumnya mencakup editor kode, kompiler atau interpreter\index{interpreter}, debugger, dan alat manajemen proyek. IDE dirancang untuk mempermudah proses pengembangan perangkat lunak dengan menyediakan antarmuka pengguna yang terintegrasi dan alat-alat yang mendukung pengkodean, pengujian, dan debugging\index{debugging}.

Untuk menulis program Python, terdapat beberapa pilihan IDE atau editor yang bisa digunakan, antara lain Visual Studio Code, IDLE (editor bawaan Python), dan PyCharm. Namun, Anda dapat menggunakan IDE atau editor lain yang Anda sukai. Buku ini menggunakan Visual Studio Code sebagai contoh.

\subsection{Cara Menginstal Visual Studio Code}

\begin{enumerate}
    \item Unduh installer VS Code dari situs resmi \url{https://code.visualstudio.com/}.
    \item Pilih installer sesuai sistem operasi Anda (Windows, macOS, atau Linux).
    \item Jalankan file installer dan ikuti petunjuk instalasi.
    \item Setelah instalasi selesai, buka aplikasi VS Code.
    \item Untuk mendukung pemrograman Python, instal ekstensi \textbf{Python} dari Microsoft melalui menu Extensions (ikon kotak di sidebar kiri).
    \item Untuk membuat file Python, buka menu File (ikon kotak di sidebar kiri) lalu pilih New File (ikon kotak di sidebar kiri) dan ketik nama file yang diinginkan diakhiri dengan \texttt{.py}. Contoh \texttt{hello.py}.
    \item Sekarang Anda dapat mulai menulis dan menjalankan kode Python di dalam VS Code.
\end{enumerate}

Setelah berkas \texttt{.py} dibuka, program dapat dijalankan dengan tombol \textit{Run Python File} di pojok kanan atas VS Code \cite{vscode-python}. Keluarannya tampil di panel terminal di bagian bawah. Cara ini menjalankan perintah yang sama dengan yang dibahas pada bagian panduan menjalankan program.

\section{Kode Python: hello_world.py}
\label{sec:hello-world-code}

\begin{lstlisting}[style=PythonStyle, caption={Kode Python: hello_world.py}, label={lst:b1-hello-world}]
print("Hello World!")
\end{lstlisting}

Kode pada Listing~\ref{lst:b1-hello-world} merupakan program Python sederhana yang mencetak "Hello World!" ke konsol. Berikut penjelasan dari setiap bagian kode tersebut:

\begin{itemize}
\item \texttt{print(...)} – \texttt{print} adalah fungsi\index{fungsi} bawaan (\textit{built-in function}) di Python yang digunakan untuk menampilkan output ke layar atau konsol.
\item \texttt{"Hello World!"} – Merupakan sebuah string\index{string} (teks) yang ditulis di dalam tanda kutip ganda. Nilai string ini akan menjadi argumen\index{argumen} yang dikirim ke fungsi \texttt{print}.
\end{itemize}


Program tersebut mencetak \texttt{Hello World!}. Python ketat terhadap penulisan. Tanda kutip yang tidak ditutup, seperti \texttt{print("Hello World!)}, menghasilkan \texttt{SyntaxError: unterminated string literal (detected at line 1)}. Huruf besar dan kecil juga dibedakan, sehingga \texttt{Print("Hello")} menghasilkan \texttt{NameError: name 'Print' is not defined. Did you mean: 'print'?}.

\section{Panduan Menjalankan Program Python}

Untuk menjalankan program Python di atas, ikuti langkah-langkah berikut:

\begin{enumerate}
	\item Buka terminal atau command prompt.
	\item Navigasikan ke direktori tempat file \texttt{hello\_world.py} disimpan (Listing~\ref{lst:b1-pindah-ke-folder-program}).
\begin{lstlisting}[language=bash, caption={Pindah ke folder program}, label={lst:b1-pindah-ke-folder-program}]
cd /path/ke/direktori
\end{lstlisting}
	\item Jalankan perintah berikut untuk menjalankan program (Listing~\ref{lst:b1-hello-world-2}):
\begin{lstlisting}[language=bash, caption={Menjalankan hello_world.py}, label={lst:b1-hello-world-2}]
python hello_world.py
\end{lstlisting}
	\item Jika tidak ada error, program akan dijalankan dan menampilkan "Hello World!" di konsol.
\end{enumerate}


Perintah \texttt{cd} pindah ke folder tempat berkas disimpan. Pada macOS dan Linux, gunakan \texttt{python3} sebagai pengganti \texttt{python}. Bila folder atau nama berkas salah, Python menampilkan pesan \texttt{can't open file} dengan keterangan \texttt{No such file or directory}. Periksa kembali folder aktif dan penulisan nama berkas.

\section{Kode Python: hello_with_input.py}

Listing~\ref{lst:b1-hello-with-input} menunjukkan contoh kodenya.

\begin{lstlisting}[style=PythonStyle, caption={Kode Python: hello_with_input.py}, label={lst:b1-hello-with-input}]
nama = input("Masukkan nama Anda: ") # Menerima input dari pengguna

print("Hello " + nama + "!") # Menampilkan output dengan input pengguna
\end{lstlisting}

Berikut penjelasan dari setiap bagian kode tersebut:

\begin{itemize}
\item \texttt{nama = input("Masukkan nama Anda: ")} - Fungsi\index{fungsi} input merupakan \textit{built-in function} yang digunakan untuk menerima input pengguna dari konsol. Fungsi ini menunda eksekusi program sampai pengguna memasukkan input dan menampilkan opsional pesan untuk meminta input yang kemudian disimpan dalam variabel\index{variabel} \texttt{nama}.
\item \texttt{print("Hello " + nama + " !")} - Seperti yang dijelaskan pada Subbab~\ref{sec:hello-world-code}, fungsi print digunakan untuk mencetak output ke layar atau konsol. Di sini, pesan "Hello [Nama]!" diisi dengan input pengguna.
\end{itemize}


Listing~\ref{lst:b1-hello-input-out} menampilkan contoh sesi saat pengguna mengetik \texttt{Rani}. Program berhenti di baris \texttt{input()} sampai pengguna menekan Enter. Hasil \texttt{input()} selalu berupa teks, dan tanda \texttt{+} pada teks berarti menyambung. Bab berikutnya membahas cara mengubah teks tersebut menjadi angka.

\begin{lstlisting}[language=bash, caption={Contoh sesi hello_with_input.py}, label={lst:b1-hello-input-out}]
Masukkan nama Anda: Rani
Hello Rani!
\end{lstlisting}

\section{Ringkasan}
Python adalah bahasa tingkat tinggi yang dijalankan oleh \textit{interpreter\index{interpreter}}, sehingga kode dapat langsung dicoba tanpa tahap kompilasi tersendiri. Menyiapkan lingkungan kerja berarti memasang Python, memastikan perintahnya dikenali terminal, dan memasang editor seperti Visual Studio Code.

Program pertama memakai dua fungsi\index{fungsi} bawaan: \texttt{print()} untuk menampilkan keluaran dan \texttt{input()} untuk menerima masukan. Dua cara menjalankannya adalah lewat terminal dan lewat tombol di editor.

\section{Latihan}

Berikut adalah beberapa latihan yang dapat Anda coba untuk memperdalam pemahaman tentang program Python yang telah dibahas:

Setiap soal di bawah ini disertai \textit{prompt} terarah. Kerjakan soal sendiri lebih dulu. Bila buntu, salin \textit{prompt} itu ke layanan AI bersama soal dan kode Anda. \textit{Prompt} ini meminta AI memberi petunjuk dan memeriksa jawaban tanpa menuliskan penyelesaiannya, sesuai pembahasan di Bab~\ref{chap:penelitian}.

\begin{enumerate}
\item \label{sec:first-exercise} \textbf{Latihan 1:} Buat file baru dengan nama \textbf{introduction.py} yang dimana program harus menerima input nama, program studi, dan tahun angkatan dari pengguna kemudian mencetak pesan dengan format yang ditentukan (Listing~\ref{lst:b1-latihan-1})
\begin{lstlisting}[style=PythonStyle, caption={Latihan 1}, label={lst:b1-latihan-1}]
nama = input("Masukkan nama Anda: ")
prodi = input("Masukkan program studi Anda: ")
angkatan = input("Masukkan tahun angkatan Anda: ")

print("Halo! Nama saya " + nama + ". Saya mahasiswa program studi " + prodi + " tahun angkatan " + angkatan + ".")
\end{lstlisting}

Contoh input dan output yang diberikan ketika program dijalankan (Listing~\ref{lst:b1-masukan-keluaran-latihan-1}):

\begin{lstlisting}[language=bash, caption={Contoh masukan dan keluaran Latihan 1}, label={lst:b1-masukan-keluaran-latihan-1}]
Input:
Masukkan Nama Anda: Bob Smith
Masukkan Program Studi Anda: Informatika
Masukkan Tahun Angkatan: 2025

Output:
Halo! Nama saya Bob Smith. Saya mahasiswa program studi Informatika tahun angkatan 2025.
\end{lstlisting}

  \begin{promptterarah}
  Saya sedang membuat program introduction.py yang meminta nama, program studi, dan tahun angkatan, lalu mencetak pesan perkenalan. Jangan tuliskan kodenya. Tanyakan dulu fungsi apa yang akan saya pakai untuk meminta masukan, lalu beri satu petunjuk bila jawaban saya keliru. Setelah saya mengirim kode, periksa dan tunjukkan bagian yang keliru tanpa memberi kode yang benar.
  \end{promptterarah}
\item \textbf{Latihan 2:} Latihan ini bertujuan untuk belajar memformat teks (\textit{string\index{string}}) menggunakan \textbf{f-string\index{f-string}}, membuat output lebih rapi tanpa perlu menggunakan operator\index{operator} \texttt{+} sebagai penghubung antara teks. Buat file baru dengan nama \textbf{introduction_with_fstring.py} dan isinya mirip dengan \hyperref[sec:first-exercise]{Latihan 1}, namun format outputnya menggunakan \textbf{f-string} (Listing~\ref{lst:b1-latihan-2})

\begin{lstlisting}[style=PythonStyle, caption={Latihan 2}, label={lst:b1-latihan-2}]
nama = input("Masukkan nama Anda: ")
prodi = input("Masukkan program studi Anda: ")
angkatan = input("Masukkan angkatan Anda: ")

print(f"Halo! Nama saya {nama}. Saya mahasiswa program studi {prodi} tahun angkatan {angkatan}. Output dihasilkan menggunakan f-string")
\end{lstlisting}

Contoh input dan output yang diberikan ketika program dijalankan (Listing~\ref{lst:b1-masukan-keluaran-latihan-2}):

\begin{lstlisting}[language=bash, caption={Contoh masukan dan keluaran Latihan 2}, label={lst:b1-masukan-keluaran-latihan-2}]
Input:
Masukkan Nama Anda: Bob Smith
Masukkan Program Studi Anda: Informatika
Masukkan Tahun Angkatan: 2025

Output:
Halo! Nama saya Bob Smith. Saya mahasiswa program studi Informatika tahun angkatan 2025.
Output dihasilkan menggunakan f-string
\end{lstlisting}

  \begin{promptterarah}
  Saya sedang belajar memformat teks dengan f-string tanpa operator +. Jangan tuliskan kodenya. Minta saya menulis satu baris f-string untuk mencetak nama saya, lalu jelaskan kesalahannya bila ada. Setelah itu beri satu kalimat lain untuk saya format sendiri.
  \end{promptterarah}
\item \textbf{Latihan 3:} \textit{Escape Character} merupakan karakter khusus yang digunakan (biasanya diawali dengan \texttt{\textbackslash}) yang digunakan di dalam string untuk mengatur penataan teks atau menampilkan karakter spesial. Dengan escape character, kita bisa:

\begin{itemize}
    \item Membuat teks pindah baris: \texttt{\textbackslash n}
    \item Menambahkan tabulasi: \texttt{\textbackslash t}
    \item Menulis tanda kutip di dalam string: \texttt{\textbackslash "}
    \item Menampilkan backslash asli: \texttt{\textbackslash\textbackslash}
\end{itemize}

Buat file baru dengan nama \textbf{escape_character.py} dan isinya seperti berikut (Listing~\ref{lst:b1-latihan-3}):

\begin{lstlisting}[style=PythonStyle, caption={Latihan 3}, label={lst:b1-latihan-3}]
print("Hello\nWorld") # Membuat teks pindah baris
print("Hello\tWorld") # Menambahkan tabulasi
print("Hello \"World") # Menulis tanda kutip di dalam string
print("Hello \\ World") # Menampilkan backslash asli
\end{lstlisting}

Output yang akan dihasilkan dari program di atas adalah (Listing~\ref{lst:b1-keluaran-latihan-3}):

\begin{lstlisting}[language=bash, caption={Keluaran Latihan 3}, label={lst:b1-keluaran-latihan-3}]
Hello
World
Hello   World
Hello "World
Hello \ World
\end{lstlisting}
  \begin{promptterarah}
  Saya sedang belajar escape character seperti \textbackslash n dan \textbackslash t. Jangan tuliskan kode jawabannya. Beri saya tiga pertanyaan singkat tentang kapan setiap escape character dipakai, lalu periksa jawaban saya. Setelah saya mengirim kode, periksa dan tunjukkan bagian yang keliru tanpa memberi kode yang benar.
  \end{promptterarah}
\end{enumerate}

\section{Soal Latihan}

Berikut adalah beberapa soal latihan tambahan untuk menguji pemahaman Anda mengenai konsep yang telah dipelajari. Seperti pada bagian Latihan, setiap soal disertai \textit{prompt} terarah.

\begin{enumerate}
\item \textbf{Soal 1:} Buat program bernama \texttt{biodata.py} yang meminta input berupa:
\begin{itemize}
	\item Nama lengkap
	\item Umur
	\item Hobi
\end{itemize}
	Cetak output dengan format berikut menggunakan \textbf{f-string\index{f-string}\index{string}}. Berikut merupakan contoh input dan output yang diharapkan (Listing~\ref{lst:b1-masukan-keluaran-soal-1}):
\begin{lstlisting}[language=bash, caption={Contoh masukan dan keluaran Soal 1}, label={lst:b1-masukan-keluaran-soal-1}]
Input:
Masukkan Nama Lengkap: Jane Hopkins
Masukkan Usia Anda: 20
Masukkan Hobi Anda: Ngoding

Output:
Halo, nama saya Jane Hopkins. Saya berusia 20 tahun dan hobi saya adalah Ngoding.
\end{lstlisting}
  \begin{promptterarah}
  Saya sedang membuat program biodata.py yang meminta nama lengkap, umur, dan hobi, lalu mencetaknya dalam satu kalimat dengan f-string. Jangan tuliskan kodenya. Tanyakan cara saya menyisipkan ketiga variabel itu ke dalam f-string, lalu beri petunjuk bila jawaban saya keliru. Setelah saya mengirim kode, periksa dan tunjukkan bagian yang keliru tanpa memberi kode yang benar.
  \end{promptterarah}

\item \textbf{Soal 2:}  
Buat program bernama \texttt{quote.py} yang menampilkan kutipan favoritmu. Gunakan \textbf{escape character} untuk menampilkan tanda kutip di dalam string. Contoh output (Listing~\ref{lst:b1-masukan-keluaran-soal-2}):

\begin{lstlisting}[language=bash, caption={Contoh masukan dan keluaran Soal 2}, label={lst:b1-masukan-keluaran-soal-2}]
Input:
Masukkan kutipan favoritmu dari Albert Einstein: "Imagination is more important
than knowledge."

Output:
Kata Albert Einstein: "Imagination is more important than knowledge."
\end{lstlisting}
  \begin{promptterarah}
  Saya sedang membuat program quote.py yang menampilkan kutipan bertanda kutip di dalam string. Jangan tuliskan kodenya. Tanyakan dua cara menampilkan tanda kutip di dalam string, termasuk dengan escape character, lalu jelaskan bila jawaban saya keliru. Setelah saya mengirim kode, periksa dan tunjukkan bagian yang keliru tanpa memberi kode yang benar.
  \end{promptterarah}

\item \textbf{Soal 3:} Buat program bernama \texttt{schedule.py} yang menampilkan jadwal kuliah. Gunakan \textbf{tabulasi} (\texttt{\textbackslash t}) untuk merapikan kolom. Contoh output ada pada Tabel~\ref{tab:b1-jadwal}:

Setelah saya mengirim kode, periksa dan tunjukkan bagian yang keliru tanpa memberi kode yang benar.
