# Checklist syarat buku ajar dan buku referensi: Dasar Pemrograman dengan GenAI Terarah

Status per 7 November 2026.

## Naskah

- [x] Buku pegangan satu mata kuliah, ditulis penulis di bidangnya
- [x] Halaman judul, pernyataan hak cipta, daftar isi, dan prakata
- [x] Tiap bab materi punya tujuan pembelajaran, ringkasan, latihan, dan referensi
- [x] Glosarium, daftar pustaka, indeks, dan riwayat penulis
- [x] Penulis sudah membaca seluruh isi, termasuk penjelasan tambahan di Bab 1 sampai 6
- [x] Kode Bab 7 sampai 14 sudah dijalankan di Python 3.10, 3.12, 3.13, dan 3.14
- [x] Penulis sudah membaca Bab 15 yang baru dan perbaikan di Bab 9, 10, 12, 13, dan 14

## Syarat buku referensi

- [x] Bab 16 disiapkan sebagai laporan penelitian berformat makalah, dengan isian merah untuk bagian yang menunggu data
- [x] Kuesioner dua lembar untuk RQ1 sampai RQ3 disiapkan di module/kuesioner
- [ ] Kuesioner sudah ditelaah ahli dan diuji coba
- [ ] Persetujuan etik sudah diperoleh
- [ ] Data penelitian terkumpul dan semua isian merah di Bab 16 terisi
- [ ] Isi memuat hasil penelitian penulis: rumusan masalah dengan kebaruan, metodologi, data, dan kesimpulan
- [ ] Daftar pustaka memuat artikel jurnal atau prosiding, termasuk publikasi penulis dari penelitian ini
- [x] Paling sedikit 125 halaman (sekarang 293)
- [ ] Penerbit menjalankan telaah sejawat eksternal, berada di luar Universitas Pradita, dan korespondensinya disimpan

## Pengajuan

- [x] Isi Bab 15 sudah diputuskan: capstone project membuat game, dengan tabel penilaian sebagai contoh
- [ ] Surat pernyataan keaslian karya bermeterai sudah ditandatangani

## Penerbitan

- [ ] Penerbit dipilih: unit penerbitan perguruan tinggi atau penerbit lain yang diakui
- [ ] Nama penerbit, tahun terbit, ISBN, editor, desainer, dan pemegang hak cipta sudah terisi
- [ ] Buku terbit dan ber-ISBN
- [ ] Buku beredar, misalnya lewat katalog penerbit, toko, atau unduhan terbuka
